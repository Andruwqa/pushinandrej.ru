# Портфолио — pushinandrej.ru

Личный сайт Андрея Пушина: продуктовый дизайнер в Контуре. Андрей — дизайнер, а не разработчик: объясняй по-русски и простыми словами, без жаргона, и перед любым пушем показывай, что меняется.

## Как устроено

- Статичные HTML-страницы, сборки нет. Минималистичная вёрстка (заголовки h1/h2, абзацы), шрифт браузера по умолчанию. Общие стили — в `style.css` (ширина колонки, отступы, переключалки). Дизайн перенесён 19.10.2026 из архивного репозитория `portfolio`.
- Страницы: `index.html` (рус) и `en/index.html` (англ.) — основная версия «для дизайнеров»; `recruiters/` и `en/recruiters/` — резюме для рекрутеров (открыто поисковикам); `merch/` и `en/merch/` — мерч; `cases/<кейс>/` и `en/cases/<кейс>/` — кейсы: `kontur-ui`, `tax-monitoring`, `fiit`, `design-update`. Кейсы и мерч пока заготовки без скриншотов (блок «Скоро здесь будут…»), закрыты от поисковиков (`noindex`) — снять, когда наполним. Вопросы к Андрею по кейсам — в HTML-комментариях `TODO`.
- В правом верхнем углу две переключалки: «дизайнерам / рекрутерам» и «рус / en». Каждая страница ссылается на свою пару на другом языке. Меняя текст на одной языковой версии, меняй и вторую.
- Ссылки между страницами — относительные папки (`en/`, `../`), поэтому локально смотреть через сервер: в папке сайта `python3 -m http.server`, потом открыть http://localhost:8000.
- Репозиторий: `Andruwqa/pushinandrej.ru` (публичный), ветка `main`.
- Хостинг: GitHub Pages, публикуется из `main`, папка `/`. Файл `CNAME` = `www.pushinandrej.ru` — не удалять.
- Основной адрес — `www.pushinandrej.ru`; `pushinandrej.ru` без www GitHub перенаправляет на него сам.
- Пуш в `main` = публикация на сайте примерно через минуту. Чтобы показать черновик, лучше сначала показать изменения локально (или скриншоты) и пушить после «да». В облачной сессии — работать в отдельной ветке и предлагать PR.
- `_config.yml` исключает `CLAUDE.md` и `README.md` из публикации на сайте. Не удалять; новые служебные файлы добавлять туда же.
- На Mac: локальная копия в `~/Documents/Sites/pushinandrej.ru`, доступ к GitHub по SSH (аккаунт Andruwqa), утилиты `gh` нет, реестр npm в рабочей сети заблокирован.
